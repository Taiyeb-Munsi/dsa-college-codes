# 💻 DSA College Codes

Standard implementations for Data Structures & Algorithms (DSA) — PCC-CS391.

This repository is designed for fellow batchmates who want standard, working college-level code without spending hours fighting with overly complex or unreliable AI-generated code. 

The goal is simple: learn the concepts, understand the implementation, and use a reliable reference when you need one.

The code is intentionally kept:

* Minimal

All implementations strictly follow the guidelines of our college (TMSL).
